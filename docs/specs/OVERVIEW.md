# Liana 產品總規格書
> 最後更新：2026-06-01
> 版本：v1.1-20260602

---

## 產品定位

Liana 是一個**個人桌面任務管理工具**，附帶手機 PWA companion。

核心價值：幫助使用者管理待辦事項、追蹤每日生活節律、回顧狀態變化。

### 三層結構

| 頁面 | 角色 | 解決的問題 |
|---|---|---|
| 今日焦點 | 執行層 | 今天要做什麼 |
| 收成紀錄 | 完成層 | 完成了什麼 |
| 每日軌跡 | 回顧層 | 最近過得如何，需要調整什麼 |

---

## 設計原則

1. **支持型，不責備型** — 不製造壓力感，不用紅色警示，不做 Streak 連續天數
2. **任務管理為核心** — 每日節律、每日軌跡是輔助層，不應喧賓奪主
3. **快速操作優先** — 常用功能一鍵完成，設定功能低調放置
4. **不做遊戲化** — 不加徽章、成就系統、排行榜

---

## 功能模組總覽

### 任務系統

**已實作：**
- 建立、編輯、刪除任務（標題、分類、到期日、詳細說明）
- 軟刪除（30 天後自動硬刪）
- 完成／取消完成（記錄 completed_at）

- 任務依賴關係（前置任務，多對多）
- 重複任務（每天、工作日、每週、每月，可設定結束日）
- 重複任務完成後自動建立下一筆
- 子任務完成時若有備註，自動附加到父任務進度紀錄（progress_log）
- 拖曳排序（manual_order）

  → 待整併到每日軌跡摘要區塊顯示（規格待定）

### 每日節律

**已實作：**

### 每日軌跡

**定位：** 狀態回顧層，不是習慣追蹤 App

**頁面結構：** 摘要 → 今日 → 歷史

**已實作：**

摘要區塊：
- 各節律項目近 7 天達標天數 + 進度條 + 狀態文字
- 滾動 7 天窗口（today 往前含今天 7 天）
- 狀態文字規則（優先順序）：
  1. 資料不足（前 7 天無紀錄）→「累積中」灰色
  2. 較前 7 天 +2 以上 →「持續進步 ↑」綠色
  3. 較前 7 天 -2 以下 →「最近減少 ↓」橘色
  4. 近 7 天 ≥ 5 天 →「維持穩定」綠色
  5. 近 7 天 ≤ 2 天 →「需要注意」橘色
  6. 其他 → 不顯示
- 每日指標最新數值與 7 天前差異（↑/↓）

今日區塊：
- 節律圓點點擊操作（同每日節律）
- 每日指標點擊直接編輯，失焦或 Enter 儲存
- 今日備註輸入

歷史區塊：
- 預設收合，展開顯示最近 30 天
- 超過 30 天顯示「查看更多」
- 每天顯示：日期、備註、各指標數值、各節律完成狀況
- 只讀

**每日指標系統：**
- 通用欄位，使用者自定義（不限於體重）
- 類型：數字、文字
- 預設指標：體重（kg，數字）
- 管理 modal：新增、編輯、軟刪除

**不實作（刻意）：**
- Streak、徽章、成就、複雜圖表

**待實作（未來）：**
- missed_count 整併到摘要顯示（規格待定）
- 歷史紀錄按月份折疊
- 指標趨勢圖
- 歷史紀錄獨立頁面

## 開發階段規劃

| 階段 | 狀態 | 內容 |
|---|---|---|
| Phase 1 | ✅ 完成 | 生命週期基礎（created_at、規格書進 Git、詳細面板顯示建立日期） |
| Phase 2 | ✅ 完成 | 收成紀錄小幅升級（耗時顯示、建立日完成日、Harvest Group 資料結構） |
| Phase 3 | ✅ 完成 | 同步擴充（節律、每日指標、備註跨裝置同步） |
| Phase 4 | ✅ 完成 | Harvest Group UI（群組拖曳、分頁同步補強） |
| Phase 5 | ✅ 完成 | Task Aging（任務年齡淡灰小字，badge 左側顯示） |

## 待辦開發清單

| 優先 | 項目 | 說明 |
|---|---|---|
| 高 | 節律與每日指標雲端同步 | 需 Supabase ALTER TABLE + 同步邏輯（Phase 3） |

| 低 | 歷史紀錄按月份折疊 | 資料量大後才需要 |
| 低 | 指標趨勢圖 | 使用一段時間後再做 |
